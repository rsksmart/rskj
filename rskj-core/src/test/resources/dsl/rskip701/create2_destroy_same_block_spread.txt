Spread twin of create2_destroy_same_block.txt: the same transactions over three blocks (b01 creates K, b02
destroys it, b03 runs the rest). The factory (salt from the call data) creates K with CREATE2 (init code returns
the 23-byte runtime). K's runtime: with 32 bytes of call data it stores 42 in slot 0 and runs SELFDESTRUCT naming
the call data; with no call data it stores 1 in slot 7. The driver calls K with the beneficiary (K is marked) and
then calls K again with no data (K stores slot 7 after its mark, in the same transaction). The probe stores
EXTCODEHASH(K) in slot 0, EXTCODESIZE(K) + 1 in slot 1 and BALANCE(K) + 1 in slot 2.
