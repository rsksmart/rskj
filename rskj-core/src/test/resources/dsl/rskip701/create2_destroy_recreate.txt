RSKIP701 cases 7 and 8. The factory creates C with CREATE2 (salt 1, init code whose runtime stores 42 in
slot 0 and then executes SELFDESTRUCT with the beneficiary taken from the call data). A call to the factory
with call data also calls C forwarding the call data; a call without call data only creates C.

C = 564277e6a03a179c7b29165fd3fa2612dd9b6602 (CREATE2 of the factory with salt 1)
accB = b88c95fb184c1a6e33aa447c12561777de55e376
callerC calls C with no value; callerZ calls an address that never exists.
